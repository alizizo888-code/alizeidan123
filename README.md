# متقن (Mutqan) — تطبيق الصيانة والخدمات

تطبيق ويب (PWA) لإدارة طلبات الصيانة بين العملاء والفنيين وغرفة العمليات والمالك، يعمل داخل ووردبريس على استضافة عادية بدون VPS ولا خدمات مدفوعة.

## المكونات
- `mutqan-app/` — واجهة التطبيق (React + Vite): تطبيق العميل، غرفة العمليات، الفني، المشرف، المالك، الخريطة الميدانية، الشات بوت المحلي.
- `oxygen-ac-automation/` — إضافة ووردبريس (الواجهة الخلفية لمتقن): الحسابات والصلاحيات، قاعدة الطلبات، بوت واتساب، الإشعارات، الدخول بالبصمة. مجلد `app/` بداخلها هو الواجهة المبنية الجاهزة.
- `wa-gateway/` — وسيط واتساب المجاني (اختياري).
- `tests/` — اختبارات التكامل (`tests/mutqan/run.sh`) واختبارات البوت (`tests/bot/run.sh`).
- `tools/` — أدوات البناء (`build-app.sh`) وتوليد بيانات البوت.
- `docs/` — التوثيق، وأهمها `docs/MUTQAN.md`.

## الفروع
- `main` و`mutqan`: مشروع متقن فقط.
- `plugin-dist-mutqan`: الإضافة جاهزة للسحب على الاستضافة (مجلد الإضافة وحده).
- `oxygen-site`: موقع أكسجين الكامل السابق (القالب والمقالات والصفحة الرئيسية).

## التركيب والبناء
راجع `docs/MUTQAN.md`. لإعادة البناء: `bash tools/build-app.sh`.

> لا تُحفظ أي كلمات مرور أو مفاتيح في هذا المستودع؛ حساب المالك يُنشأ من شاشة الإعداد في لوحة ووردبريس.
