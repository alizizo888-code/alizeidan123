# تطبيق متقن (Mutqan) — داخل ووردبريس

تطبيق ويب (يشبه التطبيق) يعمل على استضافة ووردبريس العادية بدون VPS ولا خدمات خارجية مدفوعة.

## التركيب
1. ارفع الإضافة `oxygen-ac-automation` (تحتوي مجلد `app/` الجاهز) وفعّلها.
2. من لوحة ووردبريس ← **تطبيق متقن**:
   - أنشئ حساب المالك (اسم الدخول `ali`، وكلمة المرور تكتبها أنت هناك — تُحفظ مشفّرة ولا تُكتب في أي ملف).
   - فعّل مزودي الذكاء الاصطناعي المجانيين (Groq / Gemini / Cloudflare / OpenRouter) والصق مفاتيحك. النظام ينتقل تلقائيًا للتالي عند انتهاء الحد المجاني.
3. افتح `https://oxygen11.com/app/` — الدخول للفريق من `#/staff`.
4. واتساب: من صفحة «الشات بوت والطلبات» (WhatsApp Cloud API) ليصلك كل طلب جديد.

## الأدوار
المالك ← غرفة العمليات / المشرف / الفني (الأدوار والصلاحيات يديرها المالك من «إدارة الفريق»). العميل يسجّل برقم الجوال.

## إعادة بناء الواجهة
```
cd mutqan-app && npm install
VITE_BASE=/wp-content/plugins/oxygen-ac-automation/app/ npx vite build --outDir ../oxygen-ac-automation/app --emptyOutDir
```

## الاختبارات
`tests/mutqan/run.sh` — 38 اختبار تكامل (دخول، صلاحيات، حد السعر، تبديل مزودي AI، إشعارات، تحديث لحظي).

## حدود معروفة
- لا يوجد ذكاء اصطناعي مجاني بلا أي حد؛ الحدود يومية لكل مزوّد، والجمع بين عدة مزودين يرفع السعة.
- الإشعارات داخل التطبيق (تعمل والتطبيق مفتوح)؛ إشعارات الخلفية الكاملة تحتاج مرحلة لاحقة (VAPID).
- قواعد التسعير (ومنها الحد الأدنى للتفاوض) مقروءة من المتصفح؛ الخادم يرفض أي طلب أقل من الحد، لكن نقل التفاوض بالكامل للخادم مرحلة قادمة.
- الدفع الإلكتروني غير مفعّل.

## المساعد الذكي (بدون AI ولا توكن ولا Cloud API)

- شات بوت قوي بقواعد محلية (`mutqan-app/src/localBot.js`): يفهم الخدمة والعدد والنوع، يسعّر المكيفات من جدول المالك، يفاوض ضمن الحد، ويجمع (الخدمة، التفاصيل، الموعد، الموقع، الاسم، الجوال).
- عند تأكيد العميل يُنشأ الطلب في النظام ويُفتح واتساب العميل برسالة جاهزة فيها كل البيانات ورابط الموقع إلى رقم المالك (يُضبط من «أسعار وعروض المكيفات»).
- لا يحتاج مفاتيح ولا حسابات. (بوابة LLM المجانية ما زالت اختيارية من إعدادات AI، وغير مفعّلة افتراضياً.)

اختبارات الشات بوت: `tests/bot/run.sh` (239 فحصاً: نوايا، لهجة سعودية/مصرية، فصال، تدفقات حجز كاملة، أخطاء إملائية وصوت).
قاعدة المعرفة: `mutqan-app/src/botData.js` (أكثر من 1600 نمط محادثة، 188 صيغة رد بلهجتين). اللهجة تُكتشف تلقائياً وكذلك لغة الصوت (ar-SA / ar-EG).
