# منظومة الواتساب الجماعية — 12 شريحة على سيرفر مجاني 24 ساعة

## الخلاصة

| الجزء | فين | التكلفة |
|---|---|---|
| الوسيط اللي ماسك الـ12 رقم (`wa-gateway`) | **Oracle Cloud Always Free** (سيرفر مجاني دائم) | 0 |
| صندوق الرسائل الموحد + الرد الآلي + تحويل المحادثة لطلب | ووردبريس على استضافة Hostinger الموجودة (`oxygen11.com`) | 0 إضافي |
| الردود الآلية | قواعد محلية (بدون مفاتيح AI)، ومزودين AI مجانيين اختياريًا من «إعدادات AI» | 0 |

مفيش كمبيوتر مفتوح ولا موبايل Termux. السيرفر هو اللي **بيسأل الموقع** كل 3 ثواني «فيه رسايل أبعتها؟»،
وبيبعت الرسايل الواردة للموقع أول ما توصل. يعني مفيش دومين ولا بورت مفتوح ولا نفق.

```
عملاء (إعلانات ممولة / خرائط جوجل / تيك توك / حراج)
            │ واتساب
            ▼
 12 شريحة ──► الوسيط على Oracle (24 ساعة، يرجع لوحده لو وقع)
            │  ▲  رسالة واردة + مصدرها      │  ▲  «فيه رد أبعته؟» كل 3 ث
            ▼  │                             ▼  │
     ووردبريس: صندوق موحد ← بوت يرد ← طلب في غرفة العمليات ← تنبيه للمالك
```

## ليه مش GitHub Actions؟

فكرة «مشروع على جيت هاب يتحدث كل ثانية» مش هتنفع:
- أقل جدولة في Actions **كل 5 دقايق** (ومش مضمونة)، وأي تشغيلة بتتقفل بعد **6 ساعات** بحد أقصى.
- الواتساب محتاج اتصال مفتوح طول الوقت. كل ما التشغيلة تقفل الأرقام هتفصل والرسايل تتأخر.
- شروط GitHub بتمنع استخدام Actions كسيرفر دائم لحاجة مش بناء كود، وده ممكن يقفل الحساب كله (وفيه الموقع والمقالات).

وخدمات زي Render وKoyeb وHugging Face **بتنام** لو مفيش زيارات، والملفات بتتمسح مع كل ريستارت، فهتطلب منك QR كل شوية.

## الخطوات (حوالي 20 دقيقة)

### 1) حساب Oracle
1. افتح `oracle.com/cloud/free` ← Start for free.
2. **Home Region**: اختار جدة `Saudi Arabia West (Jeddah)` أو الرياض لو ظاهرة. **مش هتقدر تغيرها بعدين**.
3. أدخل الكارت للتحقق (بيتعمل حجز صغير ويرجع).

### 2) إنشاء السيرفر
Compute ← Instances ← Create instance:
- **Image**: Canonical Ubuntu 24.04
- **Shape**: Ampere ← `VM.Standard.A1.Flex` ← **2 OCPU و12 GB** (جوه الحد المجاني)
- **SSH keys**: اختار «Generate a key pair» ونزّل المفتاح الخاص.
- Create.

> لو ظهر «Out of capacity»: جرّب Availability Domain تاني، أو جرّب بعد شوية.
> **مهم:** Oracle ممكن يسترجع السيرفرات المجانية اللي فاضية أغلب الوقت. حل الحاجتين:
> رقّي الحساب لـ **Pay As You Go**. الموارد المجانية بتفضل مجانية، وحط تنبيه ميزانية (Budget) بـ1 دولار للاحتياط.

### 3) المفتاح السري من الديسك
الديسك ← صندوق الواتساب ← الأرقام ← **إعداد الوسيط**:
- سيب **رابط الوسيط فاضي**. ده معناه إن الوسيط هو اللي بيسأل الموقع.
- انسخ **المفتاح السري**.

### 4) أمر واحد على السيرفر
ادخل على السيرفر بـSSH، من كمبيوترك أو من **Cloud Shell** (الأيقونة `>_` فوق في Oracle) بعد ما ترفع له المفتاح:
`chmod 600 key && ssh -i key ubuntu@<Public IP>`. الـIP موجود في صفحة السيرفر. وبعدين شغّل:

```bash
curl -fsSL https://raw.githubusercontent.com/alizizo888-code/alizeidan123/wa-gateway/setup-vps.sh | sudo bash
```

> لحد ما الفرع ده يتدمج في `wa-gateway`، شغّل النسخة الجديدة كده:
> `curl -fsSL https://raw.githubusercontent.com/alizizo888-code/alizeidan123/claude/whatsapp-group-system-free-i4w98i/wa-gateway/setup-vps.sh | sudo BRANCH=claude/whatsapp-group-system-free-i4w98i bash`

هيسألك عن 3 حاجات:
1. رابط الموقع: Enter.
2. المفتاح السري: الصقه.
3. الشرائح: اكتب كل شريحة بالشكل ده `id:الاسم:القناة` وافصل بينهم بفاصلة. مثال لـ12 شريحة:

```
sim01:إعلان سناب 1:ads,sim02:إعلان انستا 2:ads,sim03:إعلان 3:ads,
sim04:ماب الرياض:map,sim05:ماب جدة:map,sim06:ماب الدمام:map,
sim07:تيك توك 1:tiktok,sim08:تيك توك 2:tiktok,
sim09:حراج 1:haraj,sim10:حراج 2:haraj,sim11:حراج 3:haraj,sim12:الموقع:site
```
(اكتبهم على سطر واحد.)

لو عايز تربط بكود بدل QR، وده مفيد لو موبايل الشريحة هو اللي في إيدك، ضيف الرقم كجزء رابع:
`sim01:إعلان 1:ads:0536554731`، والكود هيظهر في `journalctl -u wa-gateway -f`.

### 5) ربط الأرقام
الديسك ← صندوق الواتساب ← الأرقام: هتلاقي QR لكل شريحة. من موبايل كل شريحة افتح:
واتساب ← ⋮ ← **الأجهزة المرتبطة** ← ربط جهاز ← امسح.

- الشرايح تفضل في الموبايلات عادي، ومش لازم الموبايلات تفضل فاتحة. بس كل موبايل لازم يفتح الإنترنت **مرة كل أسبوعين على الأقل**، وإلا واتساب بيفصل الأجهزة المرتبطة.
- تقدر تكمل ترد من الموبايل عادي. أول ما ترد بنفسك البوت بيسكت على المحادثة دي 12 ساعة، وبيتعلم من ردك.

### 6) أوامر مفيدة على السيرفر
```bash
systemctl status wa-gateway        # الحالة
journalctl -u wa-gateway -f        # اللوج المباشر وأكواد الربط
sudo nano /etc/wa-gateway.env      # تعديل الشرائح، وبعده: sudo systemctl restart wa-gateway
sudo wa-update                     # تحديث الكود مع الاحتفاظ بالأرقام المربوطة
ls /var/backups/wa-gateway         # نسخة احتياطية يومية للجلسات (آخر 7 أيام)
```

## معرفة العميل جه منين

كل محادثة بيتسجل عليها مصدرها **من أول رسالة** (أول مصدر هو اللي بيفضل)، وبيتنقل للطلب في غرفة العمليات
(`channel` / `channelName`). بالترتيب ده:

1. **إعلان ممول «ارسل رسالة واتساب»** (فيسبوك/انستجرام): بيتعرف لوحده، ومعاه رقم الإعلان وعنوانه.
2. **وسم في الرسالة الجاهزة**: حط في كل قناة رابط برسالة جاهزة فيها وسم:

| القناة | الرابط اللي تحطه |
|---|---|
| خرائط جوجل (زر الموقع/الرسائل في ملف النشاط) | `https://wa.me/9665XXXXXXXX?text=السلام%20عليكم%20%23ماب` |
| تيك توك (رابط البايو) | `https://wa.me/9665XXXXXXXX?text=السلام%20عليكم%20%23تيك` |
| حراج (في نص الإعلان) | `https://wa.me/9665XXXXXXXX?text=السلام%20عليكم%20%23حراج` |
| إعلان سناب/جوجل | `https://wa.me/9665XXXXXXXX?text=السلام%20عليكم%20%23اعلان` |
| الموقع | `https://wa.me/9665XXXXXXXX?text=السلام%20عليكم%20%23موقع` |

3. **الشريحة نفسها**: لو العميل كتب من غير وسم، بيتاخد مصدر الشريحة اللي في `SESSIONS`.
   علشان كده الأفضل تخصص شرايح لكل قناة.

## حماية الأرقام من الحظر (مهم)

الربط ده **غير رسمي** (نفس طريقة «الأجهزة المرتبطة»). واتساب ممكن يحظر أي رقم بيتصرف زي السبام، فالتزم بده:
- **الرد بس على اللي كلمك**. ممنوع الإرسال الجماعي أو مراسلة أرقام مش بادئة.
- الوسيط بيحط فاصل عشوائي (1.5 لـ5 ثواني) ومؤشر «يكتب…»، وحد يومي **150 رسالة لكل رقم** (`SEND_DAILY_CAP`).
- الشريحة الجديدة: استخدمها كام يوم عادي من الموبايل قبل ما تربطها.
- متحطش لينكات كتير في أول رد.
- لو الأرقام اللي عليها إعلانات ممولة بتجيب ضغط كبير، انقلها للـ**Cloud API الرسمي** (مجاني للرد على العميل)،
  وسيب الوسيط للخرائط وتيك توك وحراج.

## اللي اتغير في الكود

- `wa-gateway/setup-vps.sh`: تثبيت بأمر واحد (Node 22، خدمة systemd بترجع لوحدها، swap للأجهزة الصغيرة، نسخة احتياطية يومية، أمر `wa-update`).
- `wa-gateway`: متغير `SESSIONS` بيفتح كل الشرايح لوحده، وكل رسالة بتتبعت ومعاها مصدرها (`source`، `adTitle`…)،
  و`HOST=127.0.0.1` علشان محدش من بره يقدر يوصل للسيرفر.
- `class-mutqan-wa.php`: المصدر بيتحفظ على المحادثة (أول مصدر بيفضل) وعلى الطلب وفي سجل الطلب.
