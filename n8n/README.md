# n8n على الـVPS — متقن

## الربط (مرة واحدة)
1. في التطبيق: الواتساب ← **السنترال** ← انسخ «سر n8n» و«رابط الاستقبال».
2. في n8n: Workflows ← Import from File ← `mutqan-followup.json` ثم `mutqan-nightly.json`.
3. في كل workflow افتح عقدة **الإعدادات** وحط السر مكان `PASTE_SECRET_FROM_APP` (والرابط جاهز).
4. في `mutqan-followup` افتح عقدة **أحداث متقن** وانسخ الـ Production URL، والصقه في التطبيق ← السنترال ← «رابط n8n». فعّل الاتنين (Active).

## اللي بيعملوه
- **متابعة الأوردرات الجاهزة**: أي أوردر جاهز → يستنى نص ساعة → لو لسه من غير فني يبعت للماستر «⚠️ الطلب #… لسه من غير فني — رد: اعتمد …».
- **ملخص الليلة**: كل يوم 10:15 م فلوس اليوم + التنبيهات على واتساب الماستر.

## الأحداث اللي الموقع بيبعتها (موقّعة HMAC-SHA256 في هيدر `X-Mutqan-Signature`)
`order_ready` (أوردر جديد بكارت الموقع والخط) · `new_conversation` (أول رسالة من عميل) · `daily` (تقرير اليوم).

## اللي n8n يقدر يطلبه (POST على رابط الاستقبال، جسم JSON موقّع بنفس السر)
- `{"op":"master","text":"…"}` رسالة للماستر من خط التقارير.
- `{"op":"send","to":"9665…","text":"…","by":"customer|tech|report"}` من خط الدور ده.
- `{"op":"reply","order":"1234","text":"…"}` للعميل من نفس الخط اللي كلّمنا عليه.
- `{"op":"order","order":"1234"}` بيانات الطلب · `{"op":"command","text":"فلوس النهارده"}` أي أمر من أوامر المحرك الداخلي · `{"op":"lines"}` الخطوط وحالتها.
