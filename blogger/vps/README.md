# تشغيل شبكة بلوجر على السيرفر (VPS) — من غير متصفح ولا جهاز

السيرفر: `vps.oxygen11.com` (Hostinger KVM 1، Ubuntu 24.04 + n8n). النشر بيتم عن طريق Blogger API من السيرفر نفسه، كل ساعة عند الدقيقة 17 (بحد أقصى 15 عملية كتابة في الساعة: الصفحات الناقصة الأول وبعدها المقالات)، وبعد كل مرة السجل `blogger/state/published.json` بيترفع على GitHub، والتقرير اليومي بيقرا منه.

## الإعداد مرة واحدة (من الموبايل)
1. **مفتاح بلوجر:** اعمل الخطوات 1–4 في `blogger/api/SETUP.md` (Google Cloud + OAuth Playground) وخد: Client ID و Client Secret و Refresh token. اضغط **Publish app** في شاشة الموافقة عشان المفتاح ميخلصش بعد 7 أيام.
2. **مفتاح GitHub:** github.com → Settings → Developer settings → Fine-grained tokens → Generate. الريبو: `mutaqin-oxygen-app`، الصلاحية: Contents = Read and write.
3. **على السيرفر:** hPanel → VPS → Browser terminal، والصق السطر ده:
   ```
   curl -fsSL https://raw.githubusercontent.com/alizizo888-code/mutaqin-oxygen-app/mutqan/blogger/vps/setup.sh -o /root/oxy-setup.sh && bash /root/oxy-setup.sh
   ```
   هيسألك عن القيم الأربعة (مش هتظهر وانت بتكتب)، ومفاتيح الذكاء الاصطناعي اختيارية (Enter للتخطي).

## بعد كده
- السجل على السيرفر: `tail -50 /var/log/oxygen-blogger.log`
- تشغيل يدوي: `/opt/oxygen-blogger/blogger/vps/run.sh` — والحالة بس: `run.sh status`
- إيقاف النشر: `rm /etc/cron.d/oxygen-blogger`

## اللي مينفعش يتعمل من السيرفر
Blogger API مبيسمحش بإنشاء مدونات جديدة ولا تركيب القالب (Theme) ولا ربط الدومين الخاص. دول لازم يتعملوا يدوي من لوحة بلوجر. صفحات المدونة وسجلات DNS ينفع يتعملوا من السيرفر.

## الأولوية والمعدل (طلب المالك 2026-11-17)
- البداية 120 مقال في اليوم، وبيزيد 30 كل أسبوع من غير حظر لحد 300. لو بلوجر حظر، النشر بيقف لآخر اليوم والهدف بينزل خطوة.
- 90% مقالات بيع جديدة و10% بس مقالات قديمة من المولّد.
- المواضيع الأول: صيانة وإصلاح وغسيل وتركيب المكيفات، وغرف التبريد والتجميد، في مكة وجدة (60% مكيفات و40% غرف تبريد، و70% مكة).
- المدونات اللي تخصصها تكييف أو تبريد أو صيانة عامة بتاخد ضعف عدد مقالات باقي التخصصات.
- صفحات جديدة لكل مدونة: «صيانة وغسيل وتركيب المكيفات بمكة» و«بجدة»، و«غرف التبريد والتجميد بمكة» و«بجدة».
