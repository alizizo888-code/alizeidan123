# خطة نظام التوزيع والنشر المستقل (Accounts Hub)

## 1. الربط (خط ← موقع ← مقال ← منصة)
- كل **خط واتساب** (بدون اسم) يُوزّع عشوائياً متوازناً على المواقع؛ الأسماء توزَّع عشوائياً على الخطوط.
- كل مقال/صفحة هبوط يحمل **ref** داخل رسالة واتساب الأولى → البوت يعرف الموقع والمقال والمنصة والخط ويرد من نفس الرقم.
- جداول: accounts ← sites(line_id) ← articles(ref, recipe, theme) ← writes/runs.

## 2. التصميم (طبقة themes.js)
- 14 ثيماً: كلاسيكي، بدائي (التسعينات/جداول)، تقني (داكن/نيون/شبكة)، حديث (نظيف/ناعم/زجاجي)، تطبيق (بطاقات/iOS)، ترابي.
- 8 أشكال تواصل: زر عائم دائري، زر عائم بنص، شريط سفلي، شريط علوي لاصق، تبويب جانبي، قائمة منسدلة، مجموعة أزرار، أزرار داخل النص فقط.
- الاختيار بالبذرة مع تجنّب آخر 8 ثيمات؛ الألوان 8 درجات. HTML/CSS فقط (بلا JS).
- 252 وصفة عرض (شخصية × تخطيط × نبرة × طول) فوق الثيم.
- لاحقاً: ثيمات وردبريس كاملة، وأنماط لصفحات الهبوط (hero/تطبيق/دليل).

## 3. المحتوى
- أولوية قصوى: المكيفات (سبليت/شباك/دكت/كونسيلد/VRF/مركزي/باكج) والتبريد (غرف تبريد/تجميد/تشوك/ايس ميكر/أنفاق) × (صيانة/إصلاح/غسيل/تركيب/شراء/بيع مستعمل) × كل أحياء مكة (70%) وجدة، مع «أفضل/أحسن شركة».
- تخصصات ثانية: سباكة، نجارة، كهرباء، بناء، دهانات، دش… (المولد القديم حالياً).
- بوابة جودة: ≥1200 كلمة للمقال، ≥350 للهبوط، تشابه ≤0.4 للموقع و0.5 للشبكة.

## 4. النشر والفهرسة والتقارير
- 3 نوافذ يومياً (06:30، 13:00، 20:30 الرياض)، حد 15 كتابة/ساعة/حساب.
- Search Console 09:00 (خرائط الموقع + مشاكل)، تقرير 23:30، دفع GitHub.
- المراقبة: أنا أراقب عن بُعد وأعالج الأخطاء فقط؛ النظام يعمل وحده.

## 5. المتبقي
1. نشر الحاوية على VPS (يحتاج توكن GitHub للقراءة أو نسخة عامة).
2. مشروع Google Cloud (Blogger + Search Console + OAuth).
3. رفع أرقام الخطوط والأسماء من اللوحة.
4. ربط بوت الواتساب في إضافة WP بـ /bot/ref/<code>.
